## OnInit 状态

`OnInit` 方法在 `UIForm` 实例化后立即被调用，是界面逻辑初始化的关键阶段。该方法主要用于初始化 `UIFormLogic` 组件并缓存必要的组件引用，如 `Transform`。`userData` 参数可用于传递初始化数据，使界面能够根据不同的上下文进行定制化初始化。

在 `OnInit` 方法中，系统会自动缓存 `Transform` 组件，获取 `UIForm` 引用，并记录原始的图层设置，为后续的界面操作奠定基础。

## OnOpen 状态

`OnOpen` 方法在界面被打开时调用，是执行界面数据绑定、事件注册和视觉展示逻辑的理想位置。开发者应重写此方法以实现自定义的打开行为，如从数据模型加载数据、注册按钮点击事件、播放打开动画等。

该方法被调用时，系统会将界面标记为可用并设置为可见状态，确保界面在逻辑和视觉上都已准备就绪。

## OnClose 状态

`OnClose` 方法负责在界面关闭时执行必要的清理工作。这包括清理临时数据、注销事件监听器、恢复图层设置等操作，以防止内存泄漏和事件处理异常。该方法接收两个参数：`isShutdown` 和 `userData`。

`isShutdown` 参数用于区分正常关闭与框架关闭场景。当框架整体关闭时，此参数为 `true`，此时可能需要执行更彻底的清理；而正常关闭时为 `false`，执行常规清理即可。

## OnUpdate 状态

`OnUpdate` 方法在每帧被调用，适用于需要持续更新的 UI 元素，如倒计时显示、血条更新、动画效果等。由于该方法每帧执行，开发者必须注意性能开销，避免在此方法中执行耗时操作或频繁的内存分配。

该方法接收两个时间参数：`elapseSeconds`（逻辑流逝时间）和 `realElapseSeconds`（真实流逝时间），可用于实现平滑的动画和时间相关的逻辑。

## 自定义 UIFormLogic 实现示例

以下是一个完整的自定义 `UIFormLogic` 实现示例，演示了如何在各生命周期状态方法中实现典型功能：

```csharp
public class CustomUIFormLogic : UIFormLogic
{
    private Text m_TimerText;
    private float m_ElapsedTime = 0f;

    protected internal override void OnInit(object userData)
    {
        base.OnInit(userData);
        
        // 缓存组件引用
        m_TimerText = CachedTransform.Find("TimerText").GetComponent<Text>();
        
        // 使用userData进行初始化
        if (userData != null && userData is string title)
        {
            Name = title;
        }
    }

    protected internal override void OnOpen(object userData)
    {
        base.OnOpen(userData);
        
        // 数据绑定
        m_ElapsedTime = 0f;
        UpdateTimerDisplay();
        
        // 事件注册
        Button closeButton = CachedTransform.Find("CloseButton").GetComponent<Button>();
        closeButton.onClick.AddListener(OnCloseButtonClicked);
    }

    protected internal override void OnClose(bool isShutdown, object userData)
    {
        // 事件注销
        Button closeButton = CachedTransform.Find("CloseButton").GetComponent<Button>();
        closeButton.onClick.RemoveListener(OnCloseButtonClicked);
        
        base.OnClose(isShutdown, userData);
    }

    protected internal override void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        m_ElapsedTime += elapseSeconds;
        UpdateTimerDisplay();
    }

    private void OnCloseButtonClicked()
    {
        // 关闭当前界面
        UIForm.Close();
    }

    private void UpdateTimerDisplay()
    {
        if (m_TimerText != null)
        {
            m_TimerText.text = $"运行时间: {m_ElapsedTime:F1}s";
        }
    }
}
```

此示例展示了如何在 `OnInit` 中缓存组件和处理初始化数据，在 `OnOpen` 中进行数据绑定和事件注册，在 `OnClose` 中清理资源和注销事件，以及在 `OnUpdate` 中实现持续更新的倒计时功能。
